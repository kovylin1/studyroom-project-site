### 1.4. Едкая деталь

В `scrape-staggered.yml` каждый коллектор вызван через `|| true`, а шаг
«Обновить lastRunAt» идёт следом **безусловно**. Поломка молча маскируется,
а в `aggregator-schedules.json` пишется «обновлено».

### 1.5. Логин Edvoy больше не существует

На `edge.edvoy.com/login` нет поля пароля вообще: только «Sign in with OTP»
(код на почту) и Google SSO. Старый скрипт ждёт `input[type=password]` — ждать
нечего. **Чинить не нужно:** `kompas-collect-edvoy.mjs` ходит в
`api-prod.edvoy.com/edp/graphql` анонимно. Проверено 09.09: Royal Holloway —
321 курс, недобора 0. Прежнее «анонимно выдача обрезана на 100» было ошибкой
листания (`offset` там номер страницы, а не смещение), в коде уже исправлено.

### Шаг 3. Убрать маскировку поломок

- снять `|| true` с вызовов коллекторов (или проверять код возврата явно);

  (`источник вернул 0 курсов — ничего не пишем`) — это поведение не ломать.

### Шаг 4. Достроить цепочку до каталога

Новое поколение **в живой каталог не пишет**. Полный путь:

```
kompas-collect-<агрегатор>      → sources/kompas/extracts/<агрегатор>/
kompas-diff.mjs                 → кейсы сверки (sources/kompas/diff-review.json)
kompas-fees-apply.mjs и др.     → рабочая копия sources/kompas/catalog-work/
kompas-apply-workcopy.mjs       → живой каталог site/src/content/universities/
npm run build → deploy
```

**Решение владельца, без которого шаг 4 не делается:** переносить в живой каталог
автоматом в CI или оставить перенос по кнопке в панели `/manager`.
Применятель и так не пропускает карточку, нарушающую жёсткие правила гейта,
но авто-перенос означает «сверка идёт без человека».

## 5. Как воспроизвести замеры

```bash
cd scraper
node kompas-collect-edvoy.mjs --discover-only --dry-run   # сколько Edvoy отдаёт сейчас
node kompas-collect-edvoy.mjs --only=<refId> --dry-run    # точечно, проверка потолка выдачи
node kompas-collect-qahe.mjs --dry-run                    # 105 курсов против 17 у старого
node kompas-collect-qs.mjs --limit=1                      # проверка входа в портал QS
node ../scraper/audit-catalog.mjs                         # гейт деплоя
gh run view <id> --log-failed                             # почему упал scheduled-прогон
```

Все `--dry-run` ничего не пишут. У коллекторов без `--dry-run` выгрузки
перезаписываются — откат `git checkout -- <путь выгрузок>`.
