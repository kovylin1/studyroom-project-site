# StudyRoom — Control Panel

Локальная панель управления скрапером. Без БД, без логина — только для запуска на твоей машине.

## Что показывает

- **Следующий запуск по расписанию** — парсится из `.github/workflows/scrape-monthly.yml` (`cron: 0 3 1 * *`), показывает в твоём часовом поясе.
- **Источник данных** — Kaplan Pathways, базовый URL, кол-во университетов в реестре vs. в каталоге.
- **Статус последнего запуска** — idle / running / ok / fail с длительностью и временем.
- **Реестр университетов** — все 16 партнёров Kaplan, тир, есть ли в каталоге, когда последний раз обновлялись.
- **Лог последнего запуска** — живой stdout/stderr скрапера, цветовая подсветка `[ok]`/`[fail]`/`[skip]`.

## Что умеет

- **Кнопка "Запустить скрапинг сейчас"** — POST `/api/run` запускает `npm run scrape -- --all` в `../scraper`.
- **Кнопка "обновить" в строке таблицы** — POST `/api/run-one` запускает `npm run scrape -- --slug <slug>`.
- Один запуск за раз; пока идёт — кнопки отключены, пока скрапер не завершится.

## Запуск

```bash
cd control
npm start
# затем открой http://localhost:5174
```

Опционально: `PORT=8080 npm start` чтобы сменить порт.

## Зависимости

Никаких. Чистый Node 18+ (используется встроенный `node:http`, `node:child_process`).

## Зачем отдельный сервис

Главный сайт (`site/`) — статический Astro для пользователей; ему нельзя давать права запускать процессы.  
Скрапер (`scraper/`) — CLI без UI.  
Этот control-panel связывает их: дашборд + ручной триггер для тебя/менеджера, без необходимости лезть в терминал.
