## Мелочи по гигиене

- GateGuard режет каждую первую команду сессии. По правилу 1 из `CLAUDE.md` его можно
  выключить на сессию: `ECC_GATEGUARD=off`. На каталожных прогонах экономит 30–50% токенов.
- Прошлая сессия стоила ~$83. Дорого вышли просмотры больших JSON через `node -e` —
  лучше сразу писать скрипт с готовой сводкой, чем разглядывать данные по кускам.
- `npm test` в scraper гоняет vitest, а тесты написаны на `node:test`. Проверять
  `node --test scraper/*.test.mjs` — иначе «No test suite found» на зелёных тестах.
