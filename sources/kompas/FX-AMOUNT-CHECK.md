# Расходится не валюта, а сумма

Обе суммы приведены к тенге справочным курсом (`lib/country-currency.mjs`).
Расхождение до 15 % считается шумом курса. Варианты цены программы
учитываются: если с источником сходится любой из них, расхождения нет.

| Показатель | Значение |
|---|---:|
| Сверено пар «программа × источник» | 88243 |
| Валюта совпала — считает обычная сверка | 87989 |
| Валюта разная — считает этот замер | 254 |
| Из них сошлось после пересчёта | 252 |
| **Сумма расходится** | **2** |
