4. [ ] **Парсер в разные даты (разные сайты по дням недели, чтобы снизить нагрузку)**
   - 💭 Идея: расширить `.github/workflows/scrape-monthly.yml` в несколько workflow-файлов:
     - `scrape-uk-monday.yml`: cron `0 3 * * 1` (понедельник) → `--country "United Kingdom"`
     - `scrape-canada-tuesday.yml`: cron `0 3 * * 2` → `--country "Canada"`
     - Дальше USA, Australia, etc. — каждая страна свой день.
   - В `cli.ts` добавить флаг `--country <name>` для фильтра по `row.country`.
   - Бонус: можно ротировать `--slug <one_per_day>` для совсем равномерной нагрузки.

     - Добавить кнопку **"Запустить по фильтрам"** рядом с "Запустить скрапинг сейчас".
     - При клике — собрать список slug'ов из видимых (фильтрованных) строк и отправить `POST /api/run-filtered { slugs: [...] }`.
     - В `control/server.mjs` новый endpoint, который запускает `npm run scrape -- --slugs slug1,slug2,...`.
     - В `cli.ts` принимать `--slugs` множественный (split по запятой).
