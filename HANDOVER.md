# StudyRoom — передача проекта

Состояние на 10.10.2026. Этот файл — точка входа. `README.md` и `OVERVIEW.md` описывают
майский план и устарели; `BACKLOG.md` в разделе IN PROGRESS тоже держит закрытые этапы
(Stage 11–13) — открытые задачи сведены ниже.

## Что это

Каталог зарубежных вузов-партнёров StudyRoom с лендингом на каждый вуз и формой заявки.

- **Сайт:** https://studyroom-project-site.pages.dev (Cloudflare Pages, проект `studyroom-project-site`)
- **Репозиторий:** `kovylin1/studyroom-project-site`, рабочая ветка — `main`
- **Объём:** 1 076 вузов, ~124 тыс. программ, ~3 200 страниц, языки ru / en / kk
- **Стек:** Astro (статика) + Cloudflare Pages Functions (приём заявок) + Node-скрипты
  сбора данных + GitHub Actions (расписание и деплой)

Домен `studyroom.kz` — отдельный сайт на WordPress, с этим проектом не связан. Чтобы
вывести каталог на свой домен, добавьте его в Cloudflare Pages → Custom domains.

## Где что лежит

## Как обновляются данные

Всё работает само, человек нужен только при сбое.

**Ежедневная проверка в 03:00 UTC** (`scrape-staggered.yml`). Если на сегодняшнее число
назначен агрегатор, конвейер его обновляет, проверяет и сам коммитит в `main`, после чего
сайт пересобирается. GitHub иногда запускает расписание с опозданием на несколько часов —
это нормально.

| Число | Источник | Число | Источник |
|---|---|---|---|
| 1 | Kaplan | 15 | Oxford International |
| 3 | Navitas | 18 | Edvoy |
| 4 | Прямые партнёры (`direct`) — **через PR, не в прод** | 21 | IAPro |
| 6 | QAHE | 24 | QS |
| 9 | Study Group | 27 | GEDU |
| 12 | CATS (только состав) | 30 | Collab (`volk`) |

1-го числа в 06:00 UTC дополнительно идёт `scrape-monthly.yml` — сводная пересборка, в
каталог не пишет.

Новых карточек расписание не заводит — только обновляет существующие.

**Предохранители конвейера:** если изменилось больше 5 % карточек каталога, запись не
делается (список карточек уходит в панель `/manager`);
если не прошёл гейт `audit-catalog --gate`, запись не делается. В обоих случаях прогон
в Actions красный, сайт остаётся прежним.

**Прямые партнёры (4-е число)** открывают PR вместо записи в `main` — его надо
посмотреть глазами и смержить вручную.

**Деплой:** любой push в `main` запускает `deploy.yml` → сборка → Cloudflare Pages.

**Ручные запуски** (Actions → Run workflow): БОБР — кампусы и жильё, ОРЁЛ — фото,
СОРОКА — сводка, БАМБЛБИ — автофикс критичных проблем, Verify — проверка ссылок.
Кнопки «Применить решения» на странице `/manager` вызывают соответствующие `*-apply`.

## Если прогон упал

1. Actions → красный прогон → лог шага `kompas-update`. В нём видно, какой предохранитель
   сработал.
2. **Вход в портал** (IAPro, QS, Study Group): проверьте, не сменился ли пароль. Вход
   в IAPro иногда флейкает — коллектор пробует три раза; одиночный сбой можно просто
   перезапустить кнопкой с тем же агрегатором.
3. **Порог 5 %**: агрегатор массово поменял данные. Запустите локально
   `node scraper/kompas-update.mjs --agg=<имя>` **без** `--apply` — это сухой прогон,
   он покажет, что изменилось. Если изменения настоящие, запустите с `--apply --max-change=<порог>`.
4. **Гейт**: в логе перечислены нарушения по разрядам. После любой правки программ
   прогоняйте ещё `npm run build` в `site` — гейт не проверяет схему, её ловит только
   сборка (например, дедлайн, ссылающийся на удалённую программу; чинилка —
   `scraper/kompas-fix-orphan-deadlines.mjs`).

## Правила данных

- **Программы и цены — только с сайтов агрегаторов и прямых партнёров.** Офсайты вузов
  для программ и цен не парсим.
- **Есть у агрегатора — есть у нас:** вуз из выгрузки QS или Oxford International без
  карточки можно заводить.
- **Цены:** цена агрегатора важнее каталожной; при нескольких ценах на программу пишется
  минимальная, остальные — в `tuitionVariants`; среднее не считаем. Цены за семестр или
  месяц пишутся как есть с пометкой (`tuitionBasis`). Подробно — `OWNER-DECISIONS.md`.
- **Город и уровень не выдумываем:** запись без города не заводится, программа без
  распознаваемого уровня не создаётся.
- **Новое поле карточки** — сразу объявлять в `site/src/schema/university.ts`.
- `scraper/kompas-inventory.mjs --write-copy` перезаписывает рабочую копию живым
  каталогом — без нужды не запускать.

## Ключи и доступы

Значений здесь нет — их передают отдельно, не через git.

| Где | Ключи |
|---|---|
| GitHub → Settings → Secrets → Actions | `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, `IAPRO_LOGIN`, `IAPRO_PASS`, `QS_LOGIN`, `QS_PASS` |
| Cloudflare Pages → Settings → Environment variables | `CRM_WEBHOOK_URL`, `CRM_TYPE` (`bitrix24` по умолчанию или `generic`), необязательный `LEAD_NOTIFY_URL` |
| `scraper/.env` (локально, в `.gitignore`) | `IAPRO_*`, `SG_LOGIN` / `SG_PASS` / `SG_URN`, `QS_*`, `EDVOY_*`, `QAHE_*` |

Без логинов работают Kaplan, CATS, Navitas, Oxford International, GEDU, Collab.

## Открыто

**Блокирует запуск на трафик**

- **`CRM_WEBHOOK_URL` не прописан в Cloudflare.** Пока его нет, форма отвечает
  `crm_not_configured`, посетителю предлагается написать в WhatsApp, а заявка остаётся
  только в логах Pages. После установки — отправить тестовую заявку и проверить, что она
  дошла до CRM.

**Стоит проверить**

- **Decap CMS (`/admin`)** настроена на OAuth-прокси `decap-oauth.studyroom.kz`, который
  на 10.10.2026 не отвечает. Пока он не поднят, правка через браузер не работает — только
  через git. Инструкция — `DECAP_OAUTH.md`.

**На развитие**

- 5 брендов IAPro без карточки (123 программы) и 181 вуз из PDF Collab без карточки —
  по правилу «есть у агрегатора — есть у нас» их можно заводить.
- Слияние родственных карточек (один вуз под разными карточками; ссылки на «чужой» домен).
- 366 программ ведут на сайт другого вуза (nottingham → ntu, bristol → uwe,
  liverpool → xjtlu) — решить, снимать программы или только ссылку.
- Цены CATS; валюты CZK и INR в схеме.
- Потолки источников, которые не обойти парсером: QS даёт одну цену на уровень, а не на
  программу; IAPro цен не отдаёт; Study Group — «от»; GEDU — 4 бренда из 13 без списка
  курсов.

## Работа с проектом

```bash
# из корня репозитория
(cd site && npm ci && npm run build)       # сборка сайта, ~1 мин
(cd scraper && npm ci)
node scraper/kompas-update.mjs --agg=edvoy # сухой прогон одного агрегатора
node scraper/audit-catalog.mjs --gate      # гейт каталога
```

Правки — через ветку и PR в `main`; деплой после мержа идёт сам.
